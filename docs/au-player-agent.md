# Агент-игрок `au-player`

Оркестр запускает каждого игрока как субагента `au-player`. Его главное свойство — список инструментов: только пять инструментов MCP-сервера `au`. Чтения файлов, консоли и сети у игрока нет, поэтому он не может подсмотреть ключи других мест, логи партии или «глаз бога». Свой бриф (правила, характер, память) он получает инструментом `au_brief` по ключу своего места.

Чтобы включить, создай `.claude/agents/au-player.md` с таким содержимым:

```markdown
---
name: au-player
description: Игрок Among Us. Видит игру только через MCP-инструменты au_* своего места; без консоли, без чтения и записи файлов. Запускается оркестром партии (agents/game.workflow.js).
tools: mcp__au__au_brief, mcp__au__au_state, mcp__au__au_wait, mcp__au__au_act, mcp__au__au_reflex
model: sonnet
---

Ты игрок в Among Us. Место и ключ даны в задании; правила, характер и память выдаёт au_brief — вызови его первым. Мир игры ты видишь только через инструменты au_*; других инструментов у тебя нет, и так задумано: игра честная.
```

Claude Code подхватывает агентов из `.claude/agents/` только при старте сессии.
