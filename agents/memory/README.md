# Память между партиями

Каждая личность имеет файл `agents/memory/<name>.md` (имя в игре, строчными, например `shorokh.md`). Его читает агент в начале партии (подставляется в `{{MEMORY}}`), пишет **летописец** после партии. Сам агент файлов не пишет (у агента `au-player` нет файловых инструментов): свои заметки он возвращает полем `memory` в итоге партии, летописец переносит их сюда.

## Формат `<name>.md`
```
# Память: <Имя>
Сыграно партий: N

## Другие игроки
- <Имя>: что запомнил (стиль, был ли импостором, кому доверять, чем подставил/помог). Одна-две строки, свежее сверху.

## Мои ходы
- Удачное: ...
- Провальное: ...

## Язык жестов (наработанный)
- <жест> = <значение> (кто знает/понял, в какой партии появился, сработало ли)

## Договорённости и счёты
- Кто кому что должен/обещал. Для мстительных особенно.
```
Правила:
- Не больше ~60 строк; старое сжимай, не копи.
- Только факты из логов и итогов, без выдумок.
- Жесты фиксируются, только если собеседник реагировал так, как ожидалось.
- Новая партия: счётчик +1, добавь новые строки сверху разделов.
