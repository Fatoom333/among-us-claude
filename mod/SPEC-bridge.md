# AUBridge v0.1 — мод-мост

BepInEx 6 IL2CPP плагин для Among Us **v17.4e (2026.6.5), сборка Epic Games Store**. Он заменяет ручные клики: каждая копия игры сама доходит до лобби, получает своё имя и цвет и отвечает на команды по локальному сокету.

## Окружение
- Игра: `D:\AmongUs-mod` на ПК (BepInEx 6.0.0-be.788 IL2CPP x64, Reactor 2.5.1). Unity 2022.3.44f1.
- Библиотеки для сборки: `mod/refs/` — `core/` (BepInEx, Il2CppInterop, Harmony), `interop/` (Assembly-CSharp, UnityEngine.*, Il2Cppmscorlib, Hazel…), `Reactor.dll`. В git не попадают.
- На ПК запускается до 10 копий: одна на хосте, остальные в песочницах Sandboxie `AU2`…`AU10`. Папку игры они делят (Sandboxie даёт каждой копии свою копию при записи).
- Сеть: встроенный режим **«Локально»** (LAN). Свой сервер (Impostor) НЕ используем: с 17.4e он падает, а ещё занимает порт 22023, на котором локальный хост поднимает свой сервер.

## Настройка копии — аргументы командной строки
Legendary передаёт игре лишние аргументы, мод читает их через `Environment.GetCommandLineArgs()`:
- `--aub-id=N` — номер копии, 1…15.
- `--aub-mode=host|join|none` — что делать после меню. По умолчанию `none`.
- `--aub-name=Имя` — имя игрока. Не больше 10 символов; если длиннее — обрезать.
- `--aub-color=N` — номер цвета 0…17.
- `--aub-port=P` — порт моста. По умолчанию `47000+id`.
- `--aub-token=T` — общий секрет для команд, необязательный.

Без `--aub-id` мод ничего не делает. Нужно, чтобы игра без аргументов вела себя как обычная.

## Что делает v0.1
1. **Окно «Привязать гостевой аккаунт»** (account-link / merge guest popup). Его нужно закрыть **только** путём «Не сейчас», лучше всего — вообще не дать ему появиться. Ни при каком раскладе не вызывать код, который привязывает или сливает аккаунты. Если надёжно отличить «Не сейчас» нельзя, лучше ничего не делать и записать в лог. Объявления (announcements) тоже закрывать или не показывать.
2. **Имя и цвет** ставить до входа в лобби: локальные данные игрока / customization. Проверить в лобби, что другие видят именно это имя и цвет. Если цвет занят — игра выдаст другой, это нормально.
3. **Режим host**: в главном меню создать **локальную** классическую игру (то же, что «Играть → Локально → Классическая»). Карта The Skeld, максимум 15 игроков.
4. **Режим join**: найти локальную игру и зайти в неё. Повторять поиск, пока не найдёт; если не нашёл за 120 с — писать в лог и продолжать пытаться. В списке одна и та же игра встречается несколько раз (несколько сетевых адаптеров) — брать первую.
5. **Мост**: TCP-сервер **только на `127.0.0.1`** (`IPAddress.Loopback`), порт из `--aub-port`. Протокол — JSON, по одной строке на сообщение (newline-delimited):
   - запрос `{"cmd":"state"}` → `{"ok":true,"id":1,"scene":"...","mode":"host","stage":"menu|searching|lobby|ingame","name":"...","color":0,"players":[{"name":"...","color":0,"isLocal":true}]}`;
   - `{"cmd":"host"}`, `{"cmd":"join"}` — то же, что режимы выше, но по команде;
   - `{"cmd":"setname","name":"..."}`, `{"cmd":"setcolor","color":N}` — работают в меню и в лобби;
   - `{"cmd":"cosmetics"[,"category":"hats|skins|visors|pets|nameplates"][,"usable_only":true]}` -> `{"ok":true,"hats":[{"id":ProdId,"free":bool,"owned":bool[,"name":"..."]}],"skins":[..],"visors":[..],"pets":[..],"nameplates":[..],"current":{"hat","skin","visor","pet","nameplate"}}`. `owned` = `Free` или `PlayerPurchasesData.GetPurchase(ProdId, BundleId)`. Без `category` отдаёт все пять списков (размер ответа может быть десятки КБ, предел MCP-ядра - 256 КБ; если упрёмся, просить по одной категории или с `usable_only`). Лимит 8 КБ относится только к запросам.
   - `{"cmd":"setoutfit","hat":"..","skin":"..","visor":"..","pet":"..","nameplate":".."}` (все поля необязательные, нужно хотя бы одно) -> обычный снимок состояния или `{"ok":false,"error":"not owned: hat X"|"unknown hat id"|"catalog not loaded"|"bad hat"}`. Надеть можно только то, что есть в каталоге (`HatManager`) и `Free` либо куплено; ничего не открываем патчами. Мод пишет `DataManager.Player.Customization.*` и в лобби шлёт `RpcSetHat/Skin/Visor/Pet/NamePlate` (до 5 попыток на поле, пока `DefaultOutfit` не совпадёт). Пустой id не принимается: «снять» = id пустого предмета из каталога.
   - аргумент запуска `--aub-outfit=<base64 UTF-8 JSON {hat,skin,visor,pet,nameplate}>` применяется при входе, с теми же проверками (недопустимые поля отбрасываются с предупреждением в лог). launch-bridge берёт его из поля `outfit` места в `roster.json`; `agents/roster.mjs --export-pc` переносит его из строки `- Облик: {json}` файла личности.
   - `{"cmd":"abort"}` (команда оркестра, агентам-игрокам не даётся; MCP-ядро её не пробрасывает): досрочный конец партии. На любой копии: событие `game_ended {winner:"none", reason:"aborted"}` (тот же тип, что у обычного конца) и `state.game.phase="ended"`. На хосте во время игры дополнительно `GameManager.RpcEndGame(CrewmateDisconnect, false)` - все возвращаются в лобби без экрана победы роли. В лобби (игры нет) - только событие. Повторный abort не шлёт событие второй раз. Скрипт `scripts/end-game.py` шлёт abort местам 1..N. Живой проверки ещё не было.
   - если задан токен, каждый запрос обязан содержать `"token":"T"`, иначе ответ `{"ok":false,"error":"unauthorized"}`;
   - на ошибку отвечать `{"ok":false,"error":"..."}`, соединение не рвать.
6. **Лог**: всё важное писать через BepInEx logger с префиксом `[AUB]`: этапы, ошибки, полученные команды. Значение токена в лог не писать.

## Требования к коду
- **Потоки.** Сеть работает в своём потоке. Всё, что трогает Unity и игровые объекты, выполнять только в главном потоке: очередь, которую разбирает `Update` своего MonoBehaviour, или `Reactor.Utilities.Dispatcher`.
- **Безопасность.** Слушать только loopback. Ограничить длину строки (например, 8 КБ) и число соединений (например, 4). Битый JSON и неизвестная команда — это ошибка в ответе, а не исключение, которое роняет поток. Ничего не исполнять из входящих данных, кроме фиксированного списка команд. Строки от клиента (имя) проверять на длину и допустимые символы.
- **Зависимости.** Плагин помечен `[BepInDependency(ReactorPlugin.Id)]` и `[BepInProcess("Among Us.exe")]`. Сторонние пакеты NuGet — только если без них никак (System.Text.Json уже есть в .NET 6).
- **Сборка.** `net6.0`, ссылки на DLL из `mod/refs/` через `<Reference HintPath>` с `Private=false`. Проект: `mod/AUBridge/AUBridge.csproj`. Результат — один `AUBridge.dll`.
- **Названия классов игры** (AmongUsClient, MainMenuManager, DataManager, InnerNetServer, GameStartManager, попап привязки аккаунта и т.д.) не угадывать. Сверять с `mod/refs/interop/Assembly-CSharp.dll`: декомпилятор (например `ilspycmd`, ставить только в `mod/tools/` через `dotnet tool install --tool-path`) или рефлексия. Для подсказок по API можно смотреть исходники открытых модов (MalumMenu, TOU-Mira, Reactor), но у нас 17.4e.
- Код короткий и понятный, комментарии только там, где неочевидно.

## Готово, когда
- `dotnet build -c Release` собирается без ошибок.
- Мод лежит в `D:\AmongUs-mod\BepInEx\plugins\`, копия 1 запущена с `--aub-mode=host`, копии 2–3 — с `--aub-mode=join`. Через 2 минуты все три в одном лобби с разными именами, без единого клика. Этот прогон делает главный агент на ПК.
- `state` по порту каждой копии отвечает правильно.
- Окно привязки гостевого аккаунта ни разу не открылось, и ничего не привязалось.
